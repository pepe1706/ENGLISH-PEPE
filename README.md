# English Lab · Tự học tiếng Anh A1 → B2 (giọng Mỹ)

App học tiếng Anh cài được lên điện thoại như app thật, miễn phí, chạy cả khi không có mạng: 187 bài (A1–B2), bản đồ học tập, bài khóa, từ vựng, ngữ pháp, bài tập có danh sách câu và kết quả, kiểm tra cuối bài / chặng / cấp, ôn tập ngắt quãng, Ôn hôm nay, nhiệm vụ viết, thống kê kỹ năng.

## Bật trang web (1 lần)
Kho → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → **Save**. Sau 1–2 phút có link `https://<tên-tài-khoản>.github.io/<tên-kho>/`.

## Cài lên điện thoại
- **Android:** mở link bằng **Chrome** → menu **⋮** → **Cài đặt ứng dụng** (hoặc **Thêm vào màn hình chính**).
- **iPhone/iPad:** mở link bằng **Safari** → nút **Chia sẻ** → **Thêm vào MH chính**.
- Mở app lần đầu khi có mạng: app tự tải dữ liệu bài học. Sau đó học được cả khi không có mạng.

## Lưu ý
- Tiến độ lưu trên chính máy đó. Vào **Tôi → Xuất sao lưu** mỗi tuần (app nhắc sau 7 ngày). Sang máy mới: cài app rồi **Khôi phục** file sao lưu.
- Giọng đọc: **Tôi → Giọng đọc**.

## Cập nhật
- **Dữ liệu bài học:** tải file Excel mới lên kho với **đúng tên `TuHocTiengAnh.xlsx`** (ghi đè file cũ). Lần mở app tiếp theo (có mạng) app tự cập nhật, tiến độ giữ nguyên.
- **App:** thay `index.html` bằng bản build mới (`out/site/index.html`).
